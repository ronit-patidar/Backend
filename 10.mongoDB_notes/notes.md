mongoose
A library that creates a connection between mongodb and nodejs javascript runtime environment.
it is an ODM(object data modelling) library
Object Data Modeling (ODM) is a technique that lets you work with database data using objects in your programming language, instead of writing raw queries. In the MongoDB/Node.js world, this is exactly what Mongoose does for you.

The core idea

Instead of interacting with MongoDB documents as loose JSON, an ODM lets you define a schema and model in code, then work with database records as JavaScript objects with built-in structure, validation, and behavior.
