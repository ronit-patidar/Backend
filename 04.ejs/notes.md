EJS -> Embedded javascript templates
EJS is a simple templating language that lets you generate HTML markup with plain javascript.Template is like a blueprint

Interpolation syntax 
Interpolation refers to embedding expression into marked up text. we can make ejs dynamic through interpolation.

Includes -> create sub template

if we want whole html code then include is used 

<%- %> -> used for include
<% %> → run JavaScript, don't print
<%= %> → run JavaScript and print the result
